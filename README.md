# PULNET Rack Monitor: instaladores

Este repositório guarda só os **instaladores** do PULNET Rack Monitor, uso interno da PULNET Tecnologia. O código fica em outro lugar.

- Baixe o instalador mais recente em **[Releases](../../releases/latest)** (`PULNET-Rack-Monitor-Setup-<versão>.exe`).
- Os servidores já instalados (a partir da 0.8.2) avisam sozinhos quando há versão nova e se atualizam com um clique de quem tem a senha de edição.
- Cada versão vem com `atualizacao.json`, assinado digitalmente pela PULNET. O programa só instala uma atualização com essa assinatura válida.
